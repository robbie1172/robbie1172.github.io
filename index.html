PRJ-01 In progress

Wireless Radar-Camera Sensor Fusion Rig

An ESP32-CAM and ultrasonic radar stream live video and distance data to a PC running YOLO and MiDaS for object detection and depth estimation. Since AI depth maps are relative, not physical, the system uses the radar as ground truth — auto-calibrating on the fly to convert visual depth into real centimeters. The video overlay color-codes each tracked object by how well the AI's estimate matches the radar, exposing drift and blind spots in real time.
